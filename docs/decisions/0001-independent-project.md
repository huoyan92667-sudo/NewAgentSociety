# 决定 0001：新版 Agent 使用独立项目根目录

日期：2026-09-03

## 决定

新版通用 Agent 和餐厅推荐能力统一迁入仓库根目录下的 `new_agent`。该目录拥有自己的
安装配置、源码、运行入口、数据、数据库升级、基础设施、测试和文档。

## 原因

原结构把新版 Agent 与旧推荐实验放在同一个 Python 包中。即使新主循环已经重做，导入
餐厅工具时仍可能间接加载旧排序、旧配置和旧数据路径，无法证明新系统可以独立运行。

## 约束

- 新源码不得导入 `yelp_agent`；
- 正式入口不得依赖仓库根目录的旧配置或旧数据；
- 主模型只看到餐饮工具公开返回的事实和证据，不知道评论检索内部具体使用哪些算法；
- 训练程序和基准测试不得被正式运行入口导入；
- 旧代码只有在独立验证通过后才允许删除。
