# 实验记录索引

所有影响推荐质量、耗时、词元或上下文行为的实验都在这里留下可复查记录。

每次实验单独建立一个 Markdown 文件，并至少包含：

```text
实验编号与日期
要验证的问题
代码提交
模型与是否开启思考
用户编号与会话编号（涉及真实画像时）
输入问题
工具调用顺序
关键中间结果
最终完整回答
总耗时与各阶段耗时
输入词元、输出词元、模型次数、工具次数
对照版本结果
结论
发现但未处理的问题
```

迁移前已经完成的历史实验不会混入正式源码；迁移时会把仍有参考价值的真实测试结果
整理成独立记录，而不是把所有旧临时输出原样复制进来。
