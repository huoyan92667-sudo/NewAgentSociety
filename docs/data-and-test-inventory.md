# 数据、测试集与可复现性清单

本文只按 Git 实际跟踪内容说明，不把“本机磁盘上存在”误写成“GitHub 已包含”。

## GitHub 已经包含的数据

### 评论召回测评

- 一个“地道川菜”深度标注案例；
- 893 条逐评论人工/教师标签；
- 215 条当时未召回的正确证据；
- 每个批次的输入、模型原始输出、当前召回结果和总结；
- 三种评论判断方法的结果对比；
- 76 条逆向生成案例，其中固定 14 项 56 条、长尾 20 条，正反各 38 条。

位置：`data/benchmarks/review_retrieval/v1/`。

### 评论判断训练数据

- 教师候选和标签：2,142 条，14 项各 153 条；
- 教师模型原始返回、拒绝记录、分布和不一致清单；
- 学生训练集：1,723 条；
- 验证集：220 条；
- 测试集：199 条；
- 原始 Qwen3 4B 在验证集上的预测与统计；
- 教师和学生共用的输入格式与 14 项方向说明。

位置：`data/training/review_judge/`。

### 小型在线事实

- 2,447 家餐厅基础事实；
- 319 个 Yelp 原始餐饮类别及 179 个可选类别；
- 价格档位、类别表、500 家覆盖清单、14 项方向和运行校验清单。

这些小文件进入 Git；会超过普通 Git 合理体积的正文、向量和数据库没有进入。

## 本机有，但 GitHub 没有的数据

下面内容被 `.gitignore` 排除：

| 内容 | 本机已核验规模 | 原因 |
| --- | ---: | --- |
| 完整评论 | 617,718 条，约 184 MB | 大文件 |
| 评论片段 | 624,746 条，约 219 MB | 大文件 |
| 1,024 维评论向量 | 624,746 条，约 1.28 GB | 大文件 |
| Qdrant 数据目录 | 约 4.46 GB | 运行数据库，不适合普通 Git |
| PostgreSQL 数据目录 | 约 49 MB | 包含会话运行状态 |
| 用户长期画像 | 27,920 份快照、891,624 条信号 | 运行数据且体积较大 |
| 500 家完整 14 项画像数据库 | 7,000 项、51,725 条证据关系，约 56 MB | SQLite 运行库 |
| 微调模型权重 | 外部模型目录 | 模型文件不进入源码仓库 |
| 真实运行完整输出 | `runs/` | 含大量中间审计信息 |

因此，从 GitHub 全新克隆后可以阅读代码、数据规范、训练集和测评集，也可以运行不依赖
大数据的测试；但不能立刻执行完整真实推荐。必须另外提供上述运行数据，或补齐离线重建
入口后重新生成。

当前 `run/migrate_runtime_data.py` 是从旧 AgentSociety 工作区迁移现有数据的过渡工具，
其中仍列有旧目录候选路径。它不是“只靠这个新仓库和公开 Yelp 原始文件即可从零重建”
的完整方案。这是当前独立项目最明确的可复现性缺口。

## 自动测试代码迁移情况

旧工程共有 47 个相关测试文件；新项目当前有 28 个 Python 测试文件，并新增独立性检查。
测试文件数减少不等于只剩 28 条测试：当前共收集 153 条测试用例并全部通过。

已迁入并适配新包名的主线测试包括：

- Agent 模型—工具循环、参数检查、调用前后处理、异常和消耗统计；
- PostgreSQL 持久化、会话回放、上下文压缩和工作记忆；
- 统一要求、六个场景、四路融合和画像接入；
- 餐饮类别、商家事实、营业时间、距离和硬过滤；
- Qdrant 查询、评论召回、去重、证据算分、固定 14 项和逐层排序；
- 最终推荐回答、完整推荐工具和单店查询工具；
- 新源码不得导入旧 `yelp_agent` 的独立性检查。

尚未迁入新测试目录的主要是已经退出正式在线流程的离线/早期程序：

- 早期词表粗筛和单独语义粗筛；
- 旧 Cross Encoder、旧五分类实验和旧软排序；
- 旧评论切分/全量向量构建器；
- 教师候选生成、学生数据构建和原始模型评估程序；
- 500 家离线画像生成脚本；
- 逆向测评生成程序；
- 需要真实 PostgreSQL 的手动在线测试。

这些方法的结果数据和 Markdown 原始过程已经归档，但“从原始数据重新跑出相同结果”的
离线源码与测试尚未全部改造成新项目入口。不能把“结果搬过来了”说成“完整重建能力也
搬过来了”。

## 旧数据逐文件核对

旧 `recommendation_v2/data` 有 188 个 Git 跟踪文件：

- 182 个文件在新项目中存在内容完全相同的副本；
- 商家事实、类别表和对应清单改成新的运行目录与字段，内容摘要因此不同；
- 评论索引清单改写为新项目路径；
- 数据 README 按新目录重写；
- 旧 `rag_benchmark/.gitignore` 不需要继续复制。

所以，已确认的测评标签、训练样本和模型原始输出没有丢；变化集中在运行数据路径和说明
文件。完整旧 Markdown 另存于 `docs/history/legacy-snapshots/`，便于逐项复查。
